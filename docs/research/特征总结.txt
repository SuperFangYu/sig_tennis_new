                    sig_tennis_new 四种动作切分与特征总结
================================================================================
更新时间：2026-07-03
说明：本文档基于当前代码实现（algorithm/*/segmentation.py、point_track.py、rtmpose_csv.py）
      总结正手、反手、发球、截击四种动作的数据来源、特征选取与无监督切分逻辑。


================================================================================
一、整体分析流水线（四种动作通用）
================================================================================

每种动作的分析均分三步，由 backend/services/pipeline.py 编排：

  步骤1  球拍轨迹追踪（point_track）
         YOLO 自定义模型（weights/bestnew.pt）逐帧检测球拍，
         提取拍头关键点「t」的 X/Y 坐标，插值补齐 + Savitzky-Golay 平滑，
         输出：{视频名}_kpt_t_backend.csv、轨迹时序图

  步骤2  人体姿态估计（rtmpose_csv）
         YOLOv8 人体检测 + RTMPose Halpe-26 关键点估计，
         计算关节角度与身体中心坐标，
         输出：{视频名}_body_{动作}_rtmpose.csv

  步骤3  无监督动作切分（segmentation）
         融合球拍 CSV 与身体 CSV（按 frame 内连接），
         基于运动学特征检测动作区间 → 过滤 → 扩张时间窗 → 导出 MP4 片段与分析图

持拍手参数 handedness：
  - right（默认）/ left（或 l / 左手）
  - 影响关节角度列选取、部分 X 轴位移判据镜像、图表标注


================================================================================
二、公共基础特征（四种动作共用）
================================================================================

【球拍 CSV 字段】（point_track 输出）
  frame          帧序号
  time           时间（秒）
  x_raw / y_raw  原始检测坐标（缺失为 NaN）
  x_interp / y_interp  线性插值补齐
  x_clean / y_clean    Savitzky-Golay 平滑后最终轨迹（切分主用）

  追踪目标：拍头关键点「t」（球拍 5 点模型：t/l/r/b/h）
  平滑参数：window_length ≈ fps/2（奇数），polyorder=3

【身体 CSV 公共字段】（RTMPose Halpe-26 导出）
  frame, time
  body_center_x     双肩中点 X（肩宽中心，用于判断引拍侧向位置）
  body_center_y     双髋中点 Y（身体重心高度参考）
  right_elbow_angle 右肩-右肘-右腕夹角（°）
  left_elbow_angle  左肩-左肘-左腕夹角（°）
  right_knee_angle  右髋-右膝-右踝夹角（°）
  left_knee_angle   左髋-左膝-左踝夹角（°）
  shoulder_hip_angle 肩连线与髋连线夹角（°，躯干旋转/背弓）

【融合方式】
  df = merge(球拍CSV, 身体CSV, on="frame", how="inner")
  fps 估算：round(总帧数 / 末帧时间)，默认 30

【派生特征（切分时计算）】
  v_racket   = sqrt((∂x_clean)² + (∂y_clean)²)           帧间像素位移速度
  v_head     = sqrt((∂x/∂t)² + (∂y/∂t)²)                 拍头绝对速度（pixel/s）
  角度平滑   = Savitzky-Golay（fps≥26 时 window=15，否则 11，polyorder=3）

【击球时刻定位（正手/反手）】
  compute_contact_index：在波峰索引 p 至 right_base 闭区间内，
  取 v_racket 最大处作为击球帧（非直接用 Y 轴波峰）


================================================================================
三、正手击球（forehand）
================================================================================
代码：algorithm/forehand/segmentation.py

--------------------------------------------------------------------------------
3.1 峰值初筛
--------------------------------------------------------------------------------
  信号：球拍 Y 轴平滑轨迹 y_clean（T）
  方法：scipy.signal.find_peaks
  参数：
    prominence  = 45.0 px（波峰显著度）
    distance    = 1.5 秒 × fps（相邻峰最小间隔）

  每个峰 p 对应：
    left_base  = 引拍/上升段起点
    right_base = 随挥结束点

--------------------------------------------------------------------------------
3.2 多维过滤（区分正手 vs 其他波动）
--------------------------------------------------------------------------------
  在峰 p 的 [left_base, right_base] 区间内计算：

  (1) 引拍位置判据（与持拍手相关）
      右手：准备段 [start, p] 内 max(x) > avg(body_center_x) - 150
            → 拍头在身体右侧引拍
      左手：准备段内 min(x) < avg(body_center_x) + 150
            → 镜像判据，拍头在身体左侧引拍

  (2) 横向挥拍幅度
      右手：swing_width = max_x_prep - min_x_follow > 140 px
      左手：swing_width = max_x_follow - min_x_prep > 140 px

  两项均满足 → 确认为标准正手；否则标记为「位置偏移」或「横移不足」并过滤。

--------------------------------------------------------------------------------
3.3 时间窗扩张与防重叠
--------------------------------------------------------------------------------
  原始段长 = time[right_base] - time[left_base]
  动态缓冲 dynamic_buffer = clip(原始段长 × 0.8, 0.5s, 0.8s)

  start_t = time[left_base]  - dynamic_buffer
  end_t   = time[right_base] + dynamic_buffer

  防相邻动作重叠：
    若有前一峰：start_t = max(start_t, (t_prev_peak + t_curr_peak) / 2)
    若有后一峰：end_t   = min(end_t,   (t_curr_peak + t_next_peak) / 2)
    首段 start_t ≥ 0

  用 searchsorted 将 start_t/end_t 映射为帧索引，保证 MP4 与图表时间轴一致。

--------------------------------------------------------------------------------
3.4 动力链特征（持拍手选取）
--------------------------------------------------------------------------------
  右手：right_knee_angle、right_elbow_angle、shoulder_hip_angle
  左手：left_knee_angle、left_elbow_angle、shoulder_hip_angle

  输出图表（每个有效片段各一套）：
    {视频名}_kinetic_chain_{n}.png   膝角/肩髋角/肘角动力链
    {视频名}_speed_cog_{n}.png       拍头速度 + 身体重心 Y
    {视频名}_final_analysis.png      全局 Y/X 轨迹验证图
    {视频名}_Forehand_v2_{n}.mp4     切分视频

  动力链三阶段底色（以击球时刻为中心）：
    hit_window = clip(片段时长 × 0.20, 0.2s, 0.4s)
    准备（金）：[片段起点, 击球 - 0.65×hit_window]
    挥拍（绿）：[击球前65%, 击球后35%] 与片段求交
    随挥（蓝）：[绿区终点, 片段终点]

  关键参数汇总：
    PROMINENCE_THRESHOLD = 45.0
    MIN_DISTANCE_SEC     = 1.5
    EXTEND_RATIO         = 0.8
    MIN_BUFFER           = 0.5 s
    MAX_BUFFER           = 0.8 s
    MIN_SWING_WIDTH      = 140 px
    BODY_TOLERANCE       = 150 px


================================================================================
四、反手击球（backhand）
================================================================================
代码：algorithm/backhand/segmentation.py

--------------------------------------------------------------------------------
4.1 峰值初筛
--------------------------------------------------------------------------------
  与正手相同：对 y_clean 做 find_peaks
  参数差异：
    prominence  = 45.0 px
    distance    = 1.6 秒 × fps（略长于正手，避免连击误检）

--------------------------------------------------------------------------------
4.2 多维过滤（反手特有：固定左侧引拍判据）
--------------------------------------------------------------------------------
  (1) 引拍位置（不随持拍手镜像，固定检查左侧引拍）
      准备段 [start, p] 内 min(x) < avg(body_center_x) + 150
      → 拍头向身体左侧引拍（双反/单反常见模式）

  (2) 横向挥拍幅度
      swing_width = max_x_follow - min_x_prep > 200 px
      （阈值 200，高于正手 140，要求更充分的侧身挥拍）

  不满足 → 「未向左侧身引拍」或「横移不足」

--------------------------------------------------------------------------------
4.3 时间窗扩张（非对称：准备阶段补偿）
--------------------------------------------------------------------------------
  反手引拍准备时间通常更长，采用前后不对称缓冲：

  前向（准备）缓冲 prep_buffer：
    clip(原始段长 × 1.0, 1.0s, 1.5s)
  后向（随挥）缓冲 follow_buffer：
    clip(原始段长 × 0.3, 0.2s, 0.4s)

  start_t = time[left_base] - prep_buffer
  end_t   = time[right_base] + follow_buffer

  防重叠规则同正手。
  额外约束：start_t = min(start_t, hit_time - 0.2)
            → 起点不晚于击球前 0.2 秒，避免切掉击球瞬间

--------------------------------------------------------------------------------
4.4 动力链特征（持拍手：对侧肢体）
--------------------------------------------------------------------------------
  右手持拍：left_knee_angle、left_elbow_angle（非持拍侧支撑/发力链）
  左手持拍：right_knee_angle、right_elbow_angle
  共同：shoulder_hip_angle

  输出：
    {视频名}_kinetic_chain_{n}.png
    {视频名}_speed_cog_{n}.png
    {视频名}_final_analysis.png
    {视频名}_Backhand_Prep_v2_{n}.mp4

  动力链三阶段底色算法与正手相同（phase_background_times）。

  关键参数汇总：
    PROMINENCE_THRESHOLD  = 45.0
    MIN_DISTANCE_SEC      = 1.6
    PREP_EXTEND_RATIO     = 1.0
    PREP_MIN/MAX_BUFFER   = 1.0 / 1.5 s
    FOLLOW_EXTEND_RATIO   = 0.3
    FOLLOW_MIN/MAX_BUFFER = 0.2 / 0.4 s
    MIN_SWING_WIDTH       = 200 px
    BODY_TOLERANCE        = 150 px


================================================================================
五、发球（serve）
================================================================================
代码：algorithm/serve/segmentation.py

--------------------------------------------------------------------------------
5.1 峰值初筛（逆向：找 Y 轴最低点 = 击球最高点）
--------------------------------------------------------------------------------
  发球击球点对应拍头在画面中最高位置（Y 值最小）。
  信号：inverted_T = max(T) - y_clean
  方法：find_peaks(inverted_T)
  参数：
    prominence  = 80.0 px（高于底线击球，过滤小幅抖动）
    distance    = 2.5 秒 × fps（发球间隔更长）

--------------------------------------------------------------------------------
5.2 逆向溯源验证（抛球 + 挠背）
--------------------------------------------------------------------------------
  对每个候选击球峰 p，向前搜索最多 2.5 秒：

  (1) 抛球时刻
      在 [p - 2.5s, p] 窗口内，取非持拍手手腕 Y 的最小值点 → toss_idx
      右手持拍：left_wrist_y（左腕为抛球手）
      左手持拍：right_wrist_y

      抛球高度差 toss_height_diff = body_center_y[toss] - toss_wrist_y[toss]
      有效条件：toss_height_diff > 180 px（手腕明显高于髋部重心）

  (2) 挠背（拍头下压深度）
      在 [toss_idx, p] 内，球拍 Y 最大处与击球点 Y 之差：
      drop_depth = max(racket_y) - hit_racket_y
      有效条件：drop_depth > 150 px（有明显向后/向下引拍）

  完整事件链优先用于标准发球判定；事件顺序不完整、抛球高度偏低或挠背深度不足时，
  改用击球高点锚定的宽松事件链保留候选，并在摘要中标记为 relaxed，避免直接漏切。

--------------------------------------------------------------------------------
5.3 时间窗切分
--------------------------------------------------------------------------------
  start_t = toss_time - 1.8 s（抛球前准备）
  end_t   = hit_time + 1.5 s（击球后随挥）

  防重叠：与前一击球峰的中点时间取 max(start_t, ...)

  三阶段标注（图表底色）：
    准备阶段（浅蓝） ：[start_t, toss_time]
    抛球与挠背（浅黄）：[toss_time, hit_time]
    击球后（浅红）    ：[hit_time, end_t]

--------------------------------------------------------------------------------
5.4 身体特征（发球专用 CSV 额外字段）
--------------------------------------------------------------------------------
  left_wrist_y / right_wrist_y   左右手腕 Y（抛球手追踪）
  shoulder_tilt_y                双肩 Y 差（发球额外导出）
  以及公共：shoulder_hip_angle、左右膝角、左右肘角、body_center_y

  动力链图选取（按持拍手）：
    右手：right_knee_angle（蓄力腿）、right_elbow_angle（持拍手）
    左手：left_knee_angle、left_elbow_angle
    共同：shoulder_hip_angle（背弓角）

  输出：
    {视频名}_serve_trace_chart.png    球拍Y + 抛球手腕Y + 身体重心Y（双轴）
    {视频名}_serve_kinetic_chart.png  肩髋角/膝角/肘角
    {视频名}_Serve_v2_{n}.mp4

  关键参数汇总：
    PROMINENCE_THRESHOLD   = 80.0
    MIN_DISTANCE_SEC       = 2.5
    PRE_TOSS_BUFFER        = 1.8 s
    POST_HIT_BUFFER        = 1.5 s
    TOSS_HEIGHT_THRESHOLD  = 120 px
    RACKET_DROP_DEPTH      = 90 px


================================================================================
六、截击（volley）
================================================================================
代码：algorithm/volley/segmentation.py

--------------------------------------------------------------------------------
6.1 核心思路：速度突刺寻峰（非 Y 轴波峰）
--------------------------------------------------------------------------------
  截击动作短促，拍头水平速度爆发是主要特征。

  信号：v_head = sqrt((dx/dt)² + (dy/dt)²)，Savitzky-Golay 平滑（window≤11）
  方法：find_peaks(v_head)
  参数：
    prominence  = 400.0 pixel/s（高速突刺）
    width       = 0.1 秒 × fps（峰宽下限）
    distance    = 1.5 秒 × fps

  峰基区间：left_ips / right_ips，缺失时用 peak ± 0.3s 估算

--------------------------------------------------------------------------------
6.2 两大过滤法则（区别于底线抽球）
--------------------------------------------------------------------------------
  (1) 不掉拍头（轨迹紧凑）
      在爆发区间内 y_clean 的 max - min < 自适应阈值
      → 截击 Y 轴起伏小；过大则疑似底线抽球

      X 轴位移受拍摄视角和截击方式影响较大，仅作为摘要指标记录，
      不再因横移偏短或偏大直接排除候选。

  (2) 拍头立住（结构稳定）
      击球瞬间：racket_y - wrist_y < 60 px
      （Y 向下为正；差值过大说明拍头掉到手腕以下，结构垮塌）
      右手持拍用 right_wrist_y，左手用 left_wrist_y

  不满足 → 「掉拍头过深(疑似抽球)」或「拍头低于手腕(结构垮塌)」

--------------------------------------------------------------------------------
6.3 时间窗切分
--------------------------------------------------------------------------------
  截击极快，固定对称窗口：
    start_t = contact_time - 0.8 s
    end_t   = contact_time + 0.8 s

  图表展示窗口：击球点前后各 1.2 秒

--------------------------------------------------------------------------------
6.4 身体特征（截击专用）
--------------------------------------------------------------------------------
  身体 CSV 额外字段：left_wrist_y、right_wrist_y

  动力链选取（按持拍手）：
    右手：right_elbow_angle（持拍肘）、left_knee_angle（支撑腿垫步）
    左手：left_elbow_angle、right_knee_angle
    共同：shoulder_hip_angle（平稳微转）

  分析侧重点：
    膝角下降 → 分腿垫步降重心
    肘角稳定 → 手腕锁死、短促撞击
    肩髋角   → 躯干平稳而非大幅旋转

  输出（每个有效片段）：
    {视频名}_volley_trace_chart_{n}.png   拍头速度 + 球拍Y轨迹（双轴）
    {视频名}_volley_kinetic_chart_{n}.png 膝角/肘角/肩髋角
    {视频名}_Volley_v2_{n}.mp4

  击球窗底色：hit_window = 0.3s，绿区为击球点 ±0.15s

  关键参数汇总：
    prominence（速度）  = 400.0 pixel/s
    distance            = 1.5 s
    width               = 0.1 s
    Y 轴浮动上限        = 180 px
    拍头-手腕 Y 差上限   = 60 px
    切分半窗              = 0.8 s


================================================================================
七、四种动作切分逻辑对比
================================================================================

  动作   主信号            寻峰方向    核心过滤特征               时间窗策略
  ─────────────────────────────────────────────────────────────────────────
  正手   球拍 Y 轨迹       波峰        引拍侧向位置 + 横移宽度   对称动态缓冲 0.5~0.8s
  反手   球拍 Y 轨迹       波峰        左侧引拍 + 更大横移       非对称：前 1.0~1.5s / 后 0.2~0.4s
  发球   球拍 Y 轨迹       倒置波峰    抛球高度 + 挠背深度       抛球前 1.8s ~ 击球后 1.5s
  截击   拍头绝对速度      速度波峰    Y 轴紧凑 + 拍头高于手腕   击球点 ±0.8s 固定

  共同机制：
    - 均基于球拍 CSV + 身体 CSV 帧对齐融合
    - 均使用 find_peaks 做初筛 + 运动学规则二次过滤
    - 均有相邻峰中点防重叠裁剪
    - 均用 MoviePy 导出 H.264 无音频 MP4

================================================================================
十、调参建议
================================================================================

  1. 漏检（该检未检）
     - 适当降低 prominence 阈值
     - 缩短 MIN_DISTANCE_SEC（注意可能增加误检）
     - 放宽 MIN_SWING_WIDTH / TOSS_HEIGHT / 截击 Y 浮动上限

  2. 误检（不该检却检了）
     - 提高 prominence
     - 加大 MIN_DISTANCE_SEC
     - 收紧 BODY_TOLERANCE 或挥拍宽度阈值

  3. 片段过长/过短
     - 正手：调整 EXTEND_RATIO、MIN/MAX_BUFFER
     - 反手：调整 PREP_* / FOLLOW_* 缓冲参数
     - 发球：调整 PRE_TOSS_BUFFER、POST_HIT_BUFFER
     - 截击：调整 ±0.8s 固定半窗

  4. 持拍手相关
     - 正手/反手/发球/截击均支持 left/right
     - 正手会镜像 X 轴引拍判据；反手固定左侧引拍判据
     - 左手正手分析需身体 CSV 含 left_knee_angle、left_elbow_angle

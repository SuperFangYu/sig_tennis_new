五、球拍侧建议新增派生特征

可以在 CSV 中直接导出，或在后续 segmentation.py 中计算。但如果实现方便，建议在球拍 CSV 中导出以下 2D 球拍运动学特征：

1. 拍头速度

- racket_head_vx
- racket_head_vy
- racket_head_speed

计算来源：

- t_x_clean, t_y_clean
- time

2. 拍头加速度

- racket_head_ax
- racket_head_ay
- racket_head_acc

3. 球拍长轴角

- racket_long_axis_angle

建议计算：

- 从 h 点指向 t 点的向量角度
- atan2(t_y_clean - h_y_clean, t_x_clean - h_x_clean)

含义：

- 图像平面内球拍长轴方向
- 可用于判断发球、截击、正反手中的球拍姿态变化

4. 球拍宽轴/拍面代理角

- racket_width_axis_angle

建议计算：

- 从 l 点指向 r 点的向量角度
- atan2(r_y_clean - l_y_clean, r_x_clean - l_x_clean)

含义：

- 图像平面内拍框宽轴方向
- 只能作为 2D 拍面方向代理，不能写成真实三维拍面朝向

5. 拍框中心或球拍中心

- racket_center_x
- racket_center_y

建议计算：

- 可用 t/l/r/b 的 clean 坐标均值
- 如果某些点缺失，则对可用点求均值

6. 球拍五点检测质量

- racket_valid_kpt_count
- racket_mean_conf

含义：

- 当前帧有效球拍关键点数量
- 当前帧平均置信度

这些字段有助于后续判断某一帧球拍姿态是否可靠。

七、人体侧核心角度：请扩展为 8 个左右关节角 + 1 个肩髋分离角

请在 rtmpose_csv.py 中计算并导出以下 9 个角度。

1. 左肩角

字段名：

- left_shoulder_angle

计算方式：

- left_elbow - left_shoulder - left_hip
- 即以 left_shoulder 为顶点，计算左肘、左肩、左髋形成的夹角

意义：

- 反映左上臂相对躯干的位置
- 可用于分析发球上举、正反手挥拍空间、截击上肢稳定性

2. 右肩角

字段名：

- right_shoulder_angle

计算方式：

- right_elbow - right_shoulder - right_hip
- 即以 right_shoulder 为顶点，计算右肘、右肩、右髋形成的夹角

意义：

- 反映右上臂相对躯干的位置

3. 左肘角

字段名：

- left_elbow_angle

计算方式：

- left_shoulder - left_elbow - left_wrist
- 即以 left_elbow 为顶点

意义：

- 反映左臂屈伸
- 截击中可用于判断肘部是否稳定
- 发球和正反手中可用于描述挥拍臂伸展

4. 右肘角

字段名：

- right_elbow_angle

计算方式：

- right_shoulder - right_elbow - right_wrist
- 即以 right_elbow 为顶点

意义：

- 反映右臂屈伸

5. 左髋角

字段名：

- left_hip_angle

计算方式：

- left_shoulder - left_hip - left_knee
- 即以 left_hip 为顶点

意义：

- 反映左侧髋部屈伸和身体压低/蹬伸的 2D 代理特征

6. 右髋角

字段名：

- right_hip_angle

计算方式：

- right_shoulder - right_hip - right_knee
- 即以 right_hip 为顶点

意义：

- 反映右侧髋部屈伸

7. 左膝角

字段名：

- left_knee_angle

计算方式：

- left_hip - left_knee - left_ankle
- 即以 left_knee 为顶点

意义：

- 反映左腿屈伸
- 可用于分析准备、蹬伸、垫步和重心变化

8. 右膝角

字段名：

- right_knee_angle

计算方式：

- right_hip - right_knee - right_ankle
- 即以 right_knee 为顶点

意义：

- 反映右腿屈伸

9. 肩髋分离角

字段名：

- shoulder_hip_angle

计算方式：

- 肩线向量：right_shoulder - left_shoulder
- 髋线向量：right_hip - left_hip
- 计算两条线在图像平面内的夹角

意义：

- 反映肩线与髋线相对旋转/分离程度
- 是正手、反手和发球中很重要的躯干旋转 2D 代理指标
- 截击中通常变化较小，可用于区别截击和完整底线挥拍

注意：

- 这 9 个角度是研究二人体侧最核心的角度维度。
- 原有 left_elbow_angle、right_elbow_angle、left_knee_angle、right_knee_angle、shoulder_hip_angle 字段名必须保留。
- 新增 left_shoulder_angle、right_shoulder_angle、left_hip_angle、right_hip_angle。

用途：

- 发球身体伸展

九、人体-球拍相对特征建议

这些可以先不写入身体 CSV，也可以在 segmentation.py 融合球拍 CSV 和身体 CSV 后计算。为了后续动作切分与运动学分析，建议至少在融合后能计算以下特征：

1. 持拍手腕坐标

根据 handedness：

- right: racket_wrist_x = right_wrist_x, racket_wrist_y = right_wrist_y
- left: racket_wrist_x = left_wrist_x, racket_wrist_y = left_wrist_y

2. 拍头-持拍手腕距离

- racket_head_to_wrist_dist

计算：

- distance between t_x_clean/t_y_clean and racket_wrist_x/racket_wrist_y

用途：

- 挥拍半径
- 截击结构稳定性
- 正反手展开程度

3. 拍头相对持拍手腕高度

- racket_head_wrist_y_diff

计算：

- t_y_clean - racket_wrist_y

注意：

- 图像坐标 y 通常向下为正。
- 如果该值过大，说明拍头明显低于手腕。

用途：

- 截击中判断是否掉拍头
- 发球/正反手中判断球拍姿态

4. 拍头相对身体中心位置

- racket_head_rel_body_x
- racket_head_rel_body_y

计算：

- t_x_clean - body_center_x
- t_y_clean - body_center_y

用途：

- 正手/反手引拍方向
- 击球点相对身体位置

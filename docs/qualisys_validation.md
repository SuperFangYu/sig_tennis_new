# RTMPose 与 Qualisys 信效度验证方案

## 研究问题与边界

本模块验证单目 RTMPose 在侧面视频中测得的 8 个二维关节角，与 Qualisys 3D marker
投影到同一 ZY 平面后得到的角度是否一致。它属于同时效度/效标效度检验；若要报告重测
信度，还需要多个受试者、多个试次或多个测量日，不能把同一动作中的大量相邻帧当作独立样本。

本实验不使用测力台。视频和 Qualisys 文件必须来自同一次采集，但允许开始时刻、结束时刻
和帧率不同。

## 统一角度定义

两套数据均计算 0–180° 无符号三点内角，第二点是顶点：

| 角度 | 左侧定义 | 右侧定义 |
|---|---|---|
| 肩 | 肘—肩—髋 | 肘—肩—髋 |
| 肘 | 肩—肘—腕 | 肩—肘—腕 |
| 髋 | 肩—髋—膝 | 肩—髋—膝 |
| 膝 | 髋—膝—踝 | 髋—膝—踝 |

RTMPose 使用图像 x/y；Qualisys 先从三维坐标选择 Z/Y，再计算角度。坐标轴排列方向或图像
y 轴向下不会改变无符号三点内角，但镜像、左右标签和拍摄侧必须在每个试次中核对。

Qualisys 肘、腕、膝、踝默认取内外侧 marker 中点，肩使用肩 marker。当前髋临时取同侧
ASIS/PSIS 中点；这不是严格的解剖学髋关节中心，是正式验证前最需要升级的定义。优先方案是
从 QTM 已求解 Skeleton 导出髋关节中心，再让本模块读取该点。

## 为什么逐动作对齐

没有硬同步时，整段文件的第一帧通常不是同一物理时刻；30 Hz 与 100 Hz 的帧号也没有直接
对应关系。逐动作对齐用于恢复同一动作的时间对应，不是为了人为提高准确率。

每个重复动作在视频和 Qualisys 中分别标注：

1. `start`：动作开始；
2. `contact`：击球或最接近击球的共同事件；
3. `end`：随挥或动作结束。

程序用共同事件拟合 `t_qualisys = a × t_video + b`，再把 100 Hz Qualisys 角度插值到视频
帧时刻。同一重复动作的 8 个角度共用一个映射，禁止为每个关节单独找“最佳错位”。人工标注
必须保留在 CSV 中并由第二名标注者抽查。后续可用球拍/手腕速度峰自动提出候选点，但仍需质控。

## 数据流程

```text
同次采集 video.mp4 ──RTMPose──> rtmpose_8_angles.csv ┐
                                                      ├─事件对齐─> aligned_angles.csv ─> 指标
同次采集 3D TSV ──ZY投影+三点角──> qualisys_8_angles.csv ┘
```

详细命令见 [`qualisys/README.md`](../qualisys/README.md)。第一次生成两套角度后，运行
`--prepare-events`，打开两张事件表填写秒数，再运行 compare 阶段。

## 当前输出指标

- `MAE`：绝对误差的平均值，单位为度；越小越好，但应结合动作、关节、ROM 和既有研究解释。
- `RMSE`：平方误差均值的平方根，比 MAE 更惩罚少量大误差。
- `bias`：RTMPose − Qualisys 的平均误差，反映系统性高估或低估。
- `SD error` 与 `95% LoA`：误差标准差及 `bias ± 1.96 × SD` 的初步 Bland–Altman 界限。
- `Pearson r`：曲线共同变化程度；高相关不等于数值一致。
- `CCC`：同时考虑相关性与偏差的一致性指标。
- `≤5°/≤10° 比例`：便于直观报告误差分布。
- 事件误差：开始、击球、结束时刻各角度差。
- 对齐质控：时间缩放斜率、截距、锚点残差和进入比较的帧数。

当前 `all` 行只是探索性合并。视频相邻帧高度自相关，正式推断不能直接使用普通逐帧
Bland–Altman 或 ICC。样本收齐后应按受试者/试次聚类，采用重复测量 Bland–Altman、混合模型
或 cluster bootstrap，并报告 ICC 的具体模型、absolute agreement、single/average measure 及
95% CI。

## 质量控制与剔除规则

- 在分析前预先写明关键点置信度阈值、marker 缺失阈值、允许插值的最长缺口和剔除规则。
- RTMPose 当前沿用项目历史行为：角度缺失会线性插值并向首尾填充；必须在正式验证前输出并
  报告原始有效率，避免异常帧被填补后无法识别。
- Qualisys 转换不新增插值；QTM 导出的 `Mixed` trajectory 可能已含补点，应从 QTM 导出质量
  信息或在实验记录中注明。
- 每次动作检查 `alignment_qc.csv`；时间缩放异常、锚点残差过大或事件顺序错误时先修正标注，
  不应通过自由 DTW 扭曲曲线。
- 保存所有剔除原因，主分析和敏感性分析使用同一套预先确定的规则。

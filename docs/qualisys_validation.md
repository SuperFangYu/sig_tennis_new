# RTMPose–Qualisys 信效度验证方案

## 验证目标与实验边界

本实验评估单目 RTMPose 在侧面视频上获得的 8 个二维关节角，与 Qualisys marker 三维轨迹
投影到同一 ZY 平面后的角度一致性。Qualisys 作为效标/参考系统，因此当前直接得到的是同时
效度与一致性描述；若要称为“重测信度”，还必须增加重复测量日或独立重复试次设计。

实验分为正手、反手、正手截击、反手截击、发球五类，每段记录预期包含五次完整动作。
不使用测力台。视频和 TSV 可以不同帧率、不同开始/结束时刻，但必须来自同一次同步采集过程。

## 角度定义

两套数据都使用 0–180° 无符号三点内角，第二点为顶点：

| 角度 | 左侧/右侧同名点定义 |
|---|---|
| 肩角 | 肘–肩–髋 |
| 肘角 | 肩–肘–腕 |
| 髋角 | 肩–髋–膝 |
| 膝角 | 髋–膝–踝 |

RTMPose 使用图像 x/y，Qualisys 使用全局 Z/Y。坐标轴正负方向或图像 y 轴向下不会改变无符号
内角，但左右标签和摄像机是否确为目标侧面必须逐试次核对。

Qualisys 的肘、腕、膝、踝使用内外侧 marker 中点，肩使用肩 marker；当前髋用同侧 ASIS/PSIS
中点近似。该髋点不是严格的解剖学关节中心，正式分析最好换为 QTM Skeleton 求解后的髋中心，
并对两种髋定义做敏感性分析。

## 无硬同步时的自动对齐

视频帧号不能直接对应 100 Hz 的 QTM 帧号。本版允许人工填写一个视频有效时间范围，以排除
原视频前后的无效挥拍；范围只用于视频候选峰搜索，Qualisys 始终使用 TSV 全部长度。范围不
需要与 QTM 时长相等。本版不要求逐次填写起止或触球时间，而是在两套数据中使用彼此独立
测得的拍头运动作为公共时钟事件：

```text
视频原帧 ──YOLO 球拍 t 点──> 2D 拍头速度峰 ┐
                                             ├─五峰顺序匹配─> 全局仿射时间映射
QTM 3D TSV ──Racket_top Z/Y──> 2D 拍头速度峰 ┘
```

程序从候选峰中选择五个顺序一致的动作锚点。对任意相邻的第 `i`、`i+1` 对锚点，映射为：

```text
t_qualisys = q_i + (t_video - v_i) × (q_(i+1) - q_i) / (v_(i+1) - v_i)
```

四个相邻区间共同组成连续、严格递增的分段线性时间函数；第一锚点之前和第五锚点之后使用
最邻近区间的斜率外推。五次动作、八个关节共用这一个映射。随后以视频速度峰附近的速度
回落点建立五个动作窗口，并把 Qualisys 角度线性插值到映射后的视频帧时刻。

程序仍计算一条全局仿射直线的 slope、intercept、RMSE 和最大残差，但这些值只用于描述视频
时间戳的整体比例与非线性程度，不再作为实际角度时间映射。

拍头速度峰不是触球帧。当前材料只有动作、没有球也可以对齐，但输出的
`anchor_angle_errors.csv` 必须报告为“拍头速度峰时刻误差”，不能写成“触球角误差”。自动对齐
只是恢复时间对应，不改变任一角度值，也不能保证角度误差自然变小。

## 预设质量控制

- 视频 YOLO 拍头原始有效率至少 20%。
- QTM `Racket_top` 有效率至少 80%。
- 两边都至少检出五个可靠候选运动峰。
- 每个相邻锚点区间的局部斜率限制为 0.70–1.40；任一区间超出常规 0.90–1.10 时保留警告。
- 全局仿射RMSE超过0.20秒或最大残差超过0.35秒时记录诊断警告，但不阻止已通过局部斜率
  质控的分段映射。
- 自动动作窗口不得越出 Qualisys 记录范围。
- 不使用逐关节时间平移或自由 DTW 作为主要分析。

这些阈值是首版工程质控值，应先在不进入最终统计的预实验数据上检查后固定。若某一动作节奏
稳定但首版参数持续误检，应整体调整该动作在 `core/action_profiles.py` 的预设并记录版本，不能
按单个受试者反复调到结果最好。

## 输出指标

`angle_metrics.csv` 对每次重复动作和合并帧分别提供：

- `MAE`（度）：绝对误差平均值，越小表示平均偏差幅度越小。
- `RMSE`（度）：对少数大误差惩罚更明显。
- `bias`（度）：RTMPose − Qualisys 的平均误差；正数为视觉系统偏大。
- `SD error` 与 `95% LoA`：误差标准差和初步 Bland–Altman 一致性界限。
- `Pearson r`：共同变化趋势；高相关不能代替一致性。
- `CCC`：同时考虑线性相关与均值/尺度偏差。
- `≤5°`、`≤10°`：误差落在两个直观阈值内的帧比例。
- `valid_percent`：该角真正进入比较的帧比例。

还应检查 `alignment_qc.csv` 的局部斜率、全局直线诊断残差、球拍有效率与角度有效率，并人工查看
`alignment_qc.png` 中五个红色锚点是否确实对应五次动作。

## 论文阶段不能只报告逐帧结果

相邻视频帧高度自相关，因此不能把所有帧当成独立样本来夸大样本量。样本收齐后建议：

1. 以受试者 × 动作 × 重复次数为层级保存结果；
2. 报告各关节/动作的 MAE、RMSE、bias、LoA、CCC 及置信区间；
3. 使用重复测量 Bland–Altman、混合效应模型或按受试者 cluster bootstrap；
4. 若报告 ICC，明确模型、absolute agreement、single/average measure 与 95% CI；
5. 预先记录排除标准，并保留自动对齐失败的 `run_status.json`。

实际运行步骤和逐个文件说明见 [`qualisys/README.md`](../qualisys/README.md)。
